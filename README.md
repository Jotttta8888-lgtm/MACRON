# MACRON v4.5 - Agente IA Local para macOS

**MACRON** es un agente de inteligencia artificial 100% local para macOS, optimizado para Apple Silicon (MLX).

## Caracteristicas

- LLM Local via MLX
- Chat con memoria de contexto
- Reconocimiento de voz (Whisper)
- RAG de documentos locales
- Face Recognition
- Code Completion
- Menu Bar nativo
- Notificaciones de macOS
- Auto-start

## Uso

- Doble clic en MACRON.app
- Menu Bar: icono M verde
- Dock: arrastra la app
