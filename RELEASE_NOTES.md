# MACRON v4.0.0 - Release Notes

**Fecha:** 2026-07-27
**Plataforma:** macOS Apple Silicon (Mac NEO)
**Features:** 52
**Peso:** ~1.4 GB

---

## Novedades

### Inteligencia Artificial
- **Local LLM** - Soporte para modelos .gguf en Neural Engine
- **AI Vision / OCR** - Extraccion de texto nativa con Vision framework
- **Voice Pipeline Offline** - Reconocimiento de voz 100% nativo
- **Writing Tools** - Reescribir, resumir y corregir texto seleccionado

### Productividad
- **Smart File Organizer** - Organiza Downloads/Escritorio automaticamente
- **Meeting Assistant** - Detecta llamadas y silencia notificaciones
- **Smart Reminders** - Crea recordatorios contextuales en Reminders.app
- **Clipboard History** - Historial de los ultimos 50 items

### Sistema
- **System Monitor Dashboard** - CPU, RAM, bateria en tiempo real
- **Desktop Widget** - Widget flotante en el escritorio
- **Focus Mode Intelligence** - Detecta modo No Molestar
- **Crash Recovery** - Vigia cada 10 segundos

### Conectividad
- **iCloud Sync** - Sincronizacion via CloudKit
- **Apple Shortcuts** - Integracion con AppIntents
- **Plugin System** - Scripts Python, Swift, AppleScript, Shell

### Seguridad
- **Touch ID / Face ID** - Autenticacion biometrica
- **100% Local** - Cero dependencias de nube obligatorias

---

## Instalacion

1. Descarga `MACRON-v4.0.0.dmg`
2. Arrastra `MACRON.app` a `Applications`
3. Abre y concede permisos necesarios
4. Presiona `Cmd+Shift+M` para iniciar

---

## Requisitos
- macOS 14+ (Sonoma)
- Apple Silicon (M1/M2/M3/M4)
- 4 GB RAM minimo
- 2 GB espacio libre
